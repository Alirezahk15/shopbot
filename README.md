## نصب سریع

این دستور را در ترمینال سرور خود اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Alirezahk15/shopbot/main/install.sh)
```

یک منو باز می‌شود. عدد **۱** را بزنید و Enter را فشار دهید.

همین. بقیهٔ کارها در مرورگر انجام می‌شود.

---

## پیش‌نیازها

 سه چیز لازم دارید:

| مورد | توضیح |
|---|---|
| **سرور** | اوبونتو ۲۰.۰۴ به بالا یا دبیان ۱۱ به بالا، حداقل ۱ گیگ رم، دسترسی root |
| **توکن ربات** | در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید، `/newbot` را بزنید و توکن را کپی کنید |
| **شناسهٔ عددی شما** | به [@userinfobot](https://t.me/userinfobot) پیام دهید، عددی که می‌دهد شناسهٔ شماست |

> **دامنه اختیاری است.** اگر دامنه داشته باشید پنل روی HTTPS امن اجرا می‌شود. اگر نداشته باشید با IP سرور کار می‌کند و بعداً هم می‌توانید دامنه اضافه کنید.

## مرحله به مرحله

### ۱. ورود به سرور

```bash
ssh root@YOUR_SERVER_IP
```

### ۲. اجرای نصب‌کننده

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Alirezahk15/shopbot/main/install.sh)
```

منوی زیر را می‌بینید:

```
    ____  _                 ____        _
   / ___|| |__   ___  _ __ | __ )  ___ | |_
   \___ \| '_ \ / _ \| '_ \|  _ \ / _ \| __|
    ___) | | | | (_) | |_) | |_) | (_) | |_
   |____/|_| |_|\___/| .__/|____/ \___/ \__|
                     |_|
   Telegram Shop Bot  +  Admin Panel
   --------------------------------------------
   Status : not installed
   --------------------------------------------

    1)  Install ShopBot          guided web wizard
    2)  Update to latest version
    3)  Uninstall ShopBot

    4)  Restart services         5)  Start services
    6)  Stop services            7)  Service status
    8)  View logs                9)  Backup database

    10) Reset panel password     11) Setup / renew SSL

    0)  Exit
```

 عدد **۱** را بزنید.

### ۳. باز کردن ویزارد در مرورگر

نصب‌کننده بسته‌های لازم را آماده می‌کند و آدرسی مثل زیر نمایش می‌دهد:

```
  The setup wizard is starting.

  Open this address in your browser:

      http://203.0.113.45:8080
```

این آدرس را در مرورگر خود باز کنید. **ترمینال را نبندید.**

### ۴. تکمیل ویزارد

ویزارد پنج گام دارد و به فارسی و انگلیسی است (از دکمهٔ گوشهٔ صفحه زبان را عوض کنید):

| گام | چه چیزی وارد می‌کنید |
|---|---|
| **۱. خوش‌آمد** | فقط دکمهٔ شروع را بزنید |
| **۲. دامنه** | دامنه‌تان را وارد کنید، یا «دامنه ندارم» را بزنید |
| **۳. تلگرام** | توکن ربات را بچسبانید — بلافاصله بررسی می‌شود |
| **۴. حساب مدیر** | شناسهٔ عددی تلگرام و رمز عبور پنل |
| **۵. نصب** | پیشرفت کار را می‌بینید و در پایان اطلاعات ورود را می‌گیرید |

نصب معمولاً بین ۳ تا ۸ دقیقه طول می‌کشد.

### ۵. ذخیرهٔ اطلاعات ورود

در پایان، ویزارد آدرس پنل، نام کاربری و رمز عبور را نشان می‌دهد. **همان لحظه ذخیره‌شان کنید** — پس از بستن صفحه دیگر نمایش داده نمی‌شوند.

## منوی مدیریت

پس از نصب، هر وقت خواستید فقط این را بزنید:

```bash
shopbot
```

همان منو باز می‌شود، این بار با وضعیت زندهٔ سرویس‌ها:

```
   Status : installed (v32.0.0)
   Bot    : running      Panel : running
   Panel  : https://bot.example.com
```

### گزینه‌های منو

| عدد | کار |
|---|---|
| `1` | نصب ShopBot (ویزارد تحت وب) |
| `2` | به‌روزرسانی به آخرین نسخه — پیش از هر کاری از دیتابیس بکاپ می‌گیرد |
| `3` | حذف کامل — قبلش می‌پرسد که کپی دیتابیس را نگه دارد یا نه |
| `4` | ری‌استارت ربات و پنل |
| `5` | روشن کردن سرویس‌ها |
| `6` | خاموش کردن سرویس‌ها |
| `7` | وضعیت سرویس‌ها |
| `8` | مشاهدهٔ لاگ‌ها |
| `9` | بکاپ دستی از دیتابیس |
| `10` | ریست رمز عبور پنل |
| `11` | گرفتن یا تمدید گواهی SSL |
| `0` | خروج |

### اجرای مستقیم بدون منو

برای اسکریپت‌نویسی یا cron:

```bash
shopbot update      # به‌روزرسانی
shopbot restart     # ری‌استارت
shopbot status      # وضعیت
shopbot backup      # بکاپ
shopbot password    # ریست رمز
shopbot --help      # راهنمای کامل
```

## ورود به پنل

به آدرس پنل خود بروید و `login/` را به انتهایش اضافه کنید:

```
https://bot.example.com/login
```

- **نام کاربری:** `admin`
- **رمز عبور:** همان که در ویزارد تعیین کردید

### فراموشی رمز عبور

دو راه دارید:

**راه اول — از خود پنل:**

۱. در صفحهٔ ورود روی «فراموشی رمز عبور» بزنید
۲. شناسهٔ عددی تلگرام خود را وارد کنید
۳. ربات یک کد شش‌رقمی برایتان می‌فرستد (تا ۱۰ دقیقه معتبر)
۴. کد و رمز جدید را وارد کنید

> برای این کار باید حداقل یک بار به ربات `start/` داده باشید، وگرنه تلگرام اجازهٔ ارسال پیام نمی‌دهد.

**راه دوم — از ترمینال سرور:**

```bash
shopbot
# عدد 10 را بزنید
```

## رفع مشکل

<details>
<summary><b>نمی‌توانم وارد پنل شوم</b></summary>

اول وضعیت سرویس‌ها را ببینید:

```bash
shopbot status
```

اگر پنل `running` نیست، لاگش را بخوانید:

```bash
journalctl -u shopbot-panel -n 50 --no-pager
```

اگر سرویس بالاست ولی رمز پذیرفته نمی‌شود، رمز را ریست کنید:

```bash
shopbot password
```

</details>

<details>
<summary><b>ربات در تلگرام جواب نمی‌دهد</b></summary>

```bash
journalctl -u shopbot -n 50 --no-pager
```

شایع‌ترین دلیل‌ها:

- **توکن اشتباه** — فایل `opt/shopbot/.env/` را بررسی کنید
- **دو نسخه از ربات همزمان اجرا شده** — تلگرام فقط به یک کلاینت اجازهٔ polling می‌دهد. هر نسخهٔ دیگر را متوقف کنید

پس از اصلاح:

```bash
shopbot restart
```

</details>

<details>
<summary><b>ویزارد در مرورگر باز نمی‌شود</b></summary>

معمولاً فایروال پورت ۸۰۸۰ را بسته است:

```bash
sudo ufw allow 8080/tcp
```

اگر ارائه‌دهندهٔ سرور شما (مثل AWS یا Hetzner) فایروال جداگانه دارد، پورت ۸۰۸۰ را آنجا هم باز کنید.

یا از پورت دیگری استفاده کنید:

```bash
WIZARD_PORT=8090 shopbot install
```

</details>

<details>
<summary><b>گواهی SSL گرفته نشد</b></summary>

قبل از هر چیز مطمئن شوید رکورد A دامنه به IP سرور اشاره می‌کند:

```bash
dig +short bot.example.com
curl -s https://api.ipify.org
```

این دو باید یکی باشند. اگر تازه DNS را تنظیم کرده‌اید، تا چند ساعت طول می‌کشد.

بعد دوباره تلاش کنید:

```bash
shopbot
# عدد 11 را بزنید
```

</details>

<details>
<summary><b>نصب وسط کار متوقف شد</b></summary>

نصب‌کننده پیشرفت را ذخیره می‌کند. کافی است دوباره اجرا کنید:

```bash
shopbot install
```

ویزارد تشخیص می‌دهد که نصب ناتمامی وجود دارد و گزینهٔ **ادامهٔ نصب** را نشان می‌دهد. از همان جایی که متوقف شده بود ادامه می‌دهد.

لاگ کامل اینجاست:

```bash
tail -100 /var/log/shopbot-install.log
```

</details>

<details>
<summary><b>پیام apt lock می‌گیرم</b></summary>

سیستم در حال نصب به‌روزرسانی‌های خودکار است. نصب‌کننده تا ۷ دقیقه صبر می‌کند. اگر بیشتر طول کشید:

```bash
sudo lsof /var/lib/dpkg/lock-frontend
```

صبر کنید تا آن فرآیند تمام شود، بعد دوباره نصب را اجرا کنید.

</details>

## تنظیمات پیشرفته

### فایل محیط

همهٔ تنظیمات در `opt/shopbot/.env/` است. پس از هر تغییر:

```bash
shopbot restart
```

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather — **الزامی** |
| `ADMIN_IDS` | شناسه‌های عددی مدیران، با کاما جدا شوند |
| `PANEL_PASSWORD` | رمز اولیهٔ پنل |
| `JWT_SECRET` | کلید امضای توکن‌ها — حداقل ۳۲ نویسه |
| `PANEL_PORT` | پورت داخلی پنل، پیش‌فرض `8000` |
| `PANEL_TRUST_PROXY` | پشت nginx مقدار `1` بماند |
| `PANEL_CORS_ORIGINS` | دامنه‌های مجاز، با کاما جدا شوند |
| `BSCSCAN_API_KEY` | فقط برای پرداخت USDT |
| `ZARINPAL_MERCHANT_ID` | فقط برای پرداخت زرین‌پال |
| `SHOPBOT_DB` | مسیر دلخواه فایل دیتابیس |

> `JWT_SECRET` کوتاه‌تر از ۳۲ نویسه باعث می‌شود پنل عمداً بالا نیاید. این یک محافظت است، نه باگ — با کلید ضعیف هر کسی می‌تواند توکن مدیر جعل کند.

### بکاپ خودکار روزانه

```bash
sudo crontab -e
```

این خط را اضافه کنید:

```cron
0 3 * * * /usr/local/bin/shopbot backup >/dev/null 2>&1
```

بکاپ‌ها در `opt/shopbot/backups/` ذخیره می‌شوند.

### افزودن دامنه پس از نصب

```bash
shopbot
# عدد 11 را بزنید و دامنه را وارد کنید
```

## نکات امنیتی

نصب‌کننده این موارد را به‌صورت خودکار رعایت می‌کند:

- ربات و پنل با کاربر محدود `shopbot` اجرا می‌شوند، نه با root
- پنل فقط روی `127.0.0.1` گوش می‌دهد و از بیرون تنها از طریق nginx در دسترس است
- فایل `.env` با دسترسی `600` ذخیره می‌شود
- `JWT_SECRET` به‌صورت تصادفی و ۶۴ نویسه‌ای ساخته می‌شود
- رمزهای عبور با bcrypt و ۱۲ دور هش می‌شوند
- ورودهای ناموفق محدود می‌شوند تا حملهٔ حدس رمز بی‌اثر شود
- پورت ویزارد پس از پایان نصب دیگر لازم نیست و می‌توانید ببندیدش:
  ```bash
  sudo ufw delete allow 8080/tcp
  ```
